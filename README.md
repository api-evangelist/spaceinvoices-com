Space Invoices provides an embedded invoicing and compliance infrastructure for platforms, enabling multi-entity invoicing, tax rule compliance across 90+ countries, and white‑label solutions for SaaS, marketplaces, fintechs, and enterprises. The API‑first product offers sandbox, SDKs, and full OpenAPI reference to streamline integration and ensure regulatory adherence.

**Areas:** Fintech · SaaS · Invoicing · Compliance · Platform

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Space Invoices: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
